# Mounted mobile app

This directory is reserved for the Kotlin/Android app mounted on the robot. It receives frontend/backend intentions over MQTT, uses phone orientation/gyro feedback to calculate wheel effort, and publishes the existing ESP8266 MQTT envelope.

No mobile application code is implemented here yet. Start with the [mobile contract](../../docs/mobile.md), [shared interfaces](../../docs/interfaces.md), and [robot operation guide](../../docs/robot-operation.md).
